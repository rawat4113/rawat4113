</div>

> An AI-powered astronomical data-analysis pipeline designed to identify potential exoplanet transit signals from noisy **TESS stellar light-curve data**.

### 🔬 Project Highlights

- 🛰️ Processes astronomical **FITS** files
- 📈 Extracts and cleans stellar light curves
- 🧹 Removes noise and prepares astronomical observations
- 🧠 Uses Machine Learning for transit prediction
- 🔎 Detects possible exoplanet transit patterns
- 📊 Provides interactive visualization
- 🌐 Deployed as a Streamlit web application
